# UI Rules
- Premium, modern, dark, minimal, industrial, intelligent, data-focused.
- Base Palette: Black (#080808), Surface (#121212), Graphite (#1C1C1C), Border (#2A2A2A), Muted Text (#858585), Body Text (#C8C8C8), Off-White (#EAEAEA), White (#F5F5F5), Sage (#748C78), Soft Blue (#7EA6C4).
- No neon colors, no orange as primary.
- Responsive design is required.
